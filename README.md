# VokzalProject
Railway station control panel demonstration project on Qt using OOP structures.
## Описание
Проект представляет из себя демонстрационный пример разработки и миграции ПО из cli-интерфейса в полноценное оконное представление с помощью набора библиотек Qt. Пример включает в себя методы ООП, работу с файлами/БД, реализацию собственных типов данных, структур данных, межоконное взаимодействие.
#### Программа поддерживает обширный функционал:
- Загрузка/сохранение данных (в том числе автосохранение и автозагрузка при открытии программы, что позволяет автоматизировать работу)
- Представление данных в табличном виде (с возможностью сортировки)
- Удобные способы добавления/удаления/редактирования данных с защищённой проверкой корректности данных и защитой от дублирования информации
- Дополнительные функции отображения сводной информации по различным данным, финансовая сводка станции
## Технические требования
Проект был разработан и протестирован на ОС Kali Linux с помощью Qt Creator v.18.0.1. При отсутствии необходимых зависимостей, установите их.
